# Instructions
Place this `install-local.sh` script in your local aseprite repo to build and install aseprite into
your `~/.local` directory and have it discoverable by your OS.

Usage:
    ./install-local.sh                  # builds and installs aseprite
    ./install-local.sh --no-build       # installs files which were already built
    ./install-local.sh --uninstall      # uninstalls all files managed by this script
